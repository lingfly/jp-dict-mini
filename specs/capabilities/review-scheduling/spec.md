# 能力：复习调度（review-scheduling）

## 1. 目的

决定"今天该复习哪些词、以什么顺序、下次什么时候再出现"。算法用 FSRS（Free Spaced Repetition Scheduler），前端负责展示与采集评分，服务端负责持久化。

## 2. 范围

**负责**
- 查询当日到期数量（轻量）与到期卡片（全量）
- 展示待复习列表
- 采集评分（忘记/模糊/认识）与响应时间
- 提交复习结果，携带新的 FSRS 卡片状态与日志
- 学习统计展示（历史认知分布 / 新学复习构成 / 今日与未来待学）

**不负责**
- 新词从哪个词单来（见 `word-search` / `wordlist-group`）
- 个人中心的学习数字（已学习 / 已掌握 / 每日目标，见 `pages/profile`）

## 3. 关键概念

| 概念 | 含义 |
|------|------|
| `due` | 到期时间戳，早于今天 23:59:59.999 即视为今日到期 |
| `state` | 0=New，1=Learning，2=Review，3=Relearning |
| `rating` | 1=Again（忘记），2=Hard（模糊），3=Good（认识），4=Easy |
| `stability` / `difficulty` | FSRS 的稳定度与难度，决定下次间隔 |
| `INTRADAY_TRIGGERED` | 当天内再次触发（短间隔复习） |

## 4. 行为规范

### R1 到期查询

- **AC-RS-01** 当用户进入复习 Tab 时，系统应调用 `GET /api/fsrs/due-count?endTs=<今日 23:59:59.999>` 只取总数，不得拉取全部卡片。
- **AC-RS-02** 当用户点击「开始复习」时，系统应调用 `GET /api/fsrs/due?endTs=` 一次性拉取当日全部卡片。
- **AC-RS-03** 当后端返回的卡片缺少 `type` 时，系统应依据 `state` 推导：`New → NEW_WORD`，`Learning/Relearning → INTRADAY_TRIGGERED`，其余 `REGULAR_REVIEW`。
- **AC-RS-04** 当 `endTs` 计算时，系统应使用**本地时区**当天 23:59:59.999。

### R2 复习过程

- **AC-RS-05** 当卡片展示时，系统应默认隐藏答案，用户主动操作后才显示释义。
- **AC-RS-06** 当用户评分时，系统应记录**卡片展示到点击评分**之间的毫秒数作为 `responseTimeMs`，扣除页面不可见期间的时长，并按 `[0, 60000]` 截断（细则见 AC-RS-15 ~ AC-RS-19）。
- **AC-RS-07** 当提交进行中时，系统应阻止重复评分，避免同一张卡生成两条日志。
- **AC-RS-08** 当当日卡片全部完成后，系统应展示完成态，而不是空白页。

### R3 提交与状态

- **AC-RS-09** 提交时必须携带 `clientRequestId`（幂等键）、`card`、`log`、`responseTimeMs`、`fsrsVersion`。
- **AC-RS-10** 当后端返回 `3001`（单词不存在/已移出词单）时，系统应静默跳过该卡并继续下一张：不得弹任何错误提示、该卡计入已处理数、下一张的响应时间从零起算（细则见 AC-RS-20 / AC-RS-21）。
- **AC-RS-11** 当网络失败时，系统应保留当前卡片与已选评分，允许重试，不得直接跳到下一张。
- **AC-RS-12** 提交成功后，系统应使用后端返回的新卡片状态更新本地，不得由前端自行推算下次 `due`。

### R4 字段边界

- **AC-RS-13** 后端 camelCase（`elapsedDays`）与 ts-fsrs snake_case（`elapsed_days`）的转换，只允许发生在 `utils/fsrs/dataSource.js`。
- **AC-RS-14** `wordId` 全程为字符串，禁止数值化。

### R5 响应时间口径

- **AC-RS-15** 当复习页由可见变为不可见（切换 tab、进入其他页面、小程序退到后台、锁屏）时，系统应暂停当前卡片的计时。
- **AC-RS-16** 当复习页重新可见时，系统应恢复计时，不可见期间经过的时长不得计入 `responseTimeMs`。
- **AC-RS-17** 当用户点击评分时，系统应上报扣除全部不可见时长后的毫秒数，且该值不小于 0。
- **AC-RS-18** 当扣除后的时长超过 `60000` 毫秒时，系统应按 `60000` 上报；计算结果为负时按 `0` 上报。
- **AC-RS-19** 当用户在显示答案后停留任意时长再评分时，系统应将该时长计入 `responseTimeMs`，不得额外扣除，仅受 AC-RS-18 约束。
- **AC-RS-20** 当复习提交返回 `3001` 时，系统应静默跳过该卡：不展示任何错误提示，将该卡计入已处理数，并直接展示下一张。
- **AC-RS-21** 当因 `3001` 跳转到下一张卡时，系统应重置首次响应时间，下一张卡上报的 `responseTimeMs` 不得沿用上一张的值。

> 口径依据（#003）：Anki 手册明确"作答时长不参与调度"（`The time taken does not influence scheduling`），计时区间为「题目出现 → 按评分键」，因此看答案计入、离开页面扣除、单卡上限 60 秒。

### R6 用户自定义参数

参数存服务端 `learning-config`（`fsrsRequestRetention` / `fsrsMaximumInterval`），默认 `0.90` / `36500`（界面「不限」）。

- **AC-RS-22** 当小程序冷启动进入复习页时，系统应先等待静默登录完成，再请求学习配置。
- **AC-RS-23** 当计算评分预览或下次复习时，系统应使用当前参数，优先级为：本次运行内设置页保存值 → 服务端 → 本机缓存（仅请求失败）→ 默认值。
- **AC-RS-24** 当服务端返回参数时，系统应使用服务端值计算并写入本机缓存；缓存不得覆盖服务端值。
- **AC-RS-25** 当参数请求失败且无缓存时，系统应使用默认值继续答题，不阻塞复习。
- **AC-RS-26** 当设置页保存成功后，下一次展示卡片即使用新值；重启后从服务端重新读取并继续生效。
- **AC-RS-27** 参数变化不得修改已有卡片的 `due` / `stability` / `difficulty` / `state`，不得触发重排或批量写。
- **AC-RS-28** 设置页应分为「通用设置」（现有四项，仅标题）、「复习参数」（标题行右侧「恢复默认」）、「管理员配置」三组。
- **AC-RS-29** 目标记忆保持率应为四档选择器（80%/85%/90%/95%，默认 90%）。
- **AC-RS-30** 最大复习间隔应为六档选择器（30/90/180/365/730/不限，默认「不限」）。
- **AC-RS-31** 保存时应只提交本次修改的字段（后端部分更新）；成功后更新显示并提示「已更新」。
- **AC-RS-32** 当保存失败（业务码非 200，如 `2005`，或网络失败）时，界面应回滚；错误提示由 `utils/request.js` 统一给出一次，页面不得重复提示。
- **AC-RS-33** 当用户确认「恢复默认」时，系统应显式提交两项默认值（`0.90` / `36500`）。
- **AC-RS-34** 当服务端参数缺失、为 `null`、类型错误或不在档位集合内时，系统应按字段回落默认值，不得抛出 `FSRSValidationError`。
- **AC-RS-35** 当后端未提供新字段时（旧版本），系统应使用默认值、不报错；保存接口不可用时回滚并提示。
- **AC-RS-36** 参数变化不得改变评分映射、`responseTimeMs` 口径、3001 静默、失败停留当前卡、队列回插规则、`fsrsVersion`。

> 依据（#004）：默认值 `0.90/36500` 与后端 DDL `0.900/36500` 必须同值；接口为部分更新，失败码 `2005`。详见 `changes/004-fsrs-user-parameters/`。

### R7 学习统计

页面 `pages/review-forecast`，标题「学习统计」。数据来自 `GET /api/fsrs/due-forecast`，响应为 `data.days`，长度固定 106（前 90 天 + 今天 + 后 15 天，升序，今天下标 90）。页面提供两个**互不联动**的图表：认知情况（默认）与新学复习。

- **AC-RS-37** 当用户进入学习统计页时，系统应先等待静默登录完成，再请求统计接口。
- **AC-RS-38** 系统应按后端 `days` 顺序渲染全部日期，不得自行推算日期序列；不得读取任何已删除的旧字段。
- **AC-RS-39** 当 `days` 缺失、为空或非数组时，系统应展示「暂无学习记录」；请求失败时展示「加载失败」与「重试」，错误提示只由请求层给出一次。
- **AC-RS-40** 页面顶部应提供「认知情况」「新学复习」两个切换项，默认选中「认知情况」；切换时选中日期重置为今天并滚回今天居中。
- **AC-RS-41** 「认知情况」柱由简单、认识、模糊、忘记、待学五段堆叠；「新学复习」柱由新学、复习、待学三段堆叠；柱总高为各段之和。
- **AC-RS-42** 两个图表应共用同一纵轴上限，同一天在两图中的柱总高度相同。
- **AC-RS-43** 数值为 `0` 的段不绘制；大于 `0` 但高度不足 4rpx 的段按 4rpx 绘制。
- **AC-RS-44** 数值为 `null` 的段不绘制，且不得按 `0` 处理（未来日的认知/新学复习、历史日的待学）。
- **AC-RS-45** 图表一屏应展示 7 天，其余日期横向滑动查看；横轴标注为前天/昨天/今天/明天/后天/N天前/N天后。
- **AC-RS-46** 当用户点击某一列时，系统应高亮该列并在图表下方常驻详情卡展示该日全部数值与学习时长。
- **AC-RS-47** 详情卡对不存在的项显示「—」；未来日只展示日期与待学，其余「—」，并提示「这一天还没到」。
- **AC-RS-48** 学习时长按「N 分 N 秒」展示，不足 1 分钟为「N 秒」，0 为「0 秒」。

> 依据（#005）：接口为破坏性变更，旧字段全部删除；`null` 与 `0` 语义不同，必须区分。详见 `changes/005-learning-stats/`。

## 5. 边界与异常

| 场景 | 预期行为 | 当前实现 |
|------|----------|----------|
| 后端 FSRS 未就绪 | 使用本地 mock 数据，页面无感 | `USE_MOCK` 开关（当前为 `false`） |
| 卡片对应单词已删除 | 静默跳过：不弹提示、计入已处理、重置计时 | `WORD_NOT_FOUND = 3001`（#003） |
| 页面切走 / 退到后台 | 暂停计时，回来继续，离开时长不计入 | `utils/reviewTimer.js`（#003） |
| 单卡停留超过 60 秒 | 按 60 秒记录 | `MAX_RESPONSE_TIME_MS`（#003） |
| 重复点击评分 | 只提交一次 | 页面提交锁 + `clientRequestId` |
| 跨天复习 | 以进入页面时的 `endTs` 为准，不中途重算 | `endOfToday()` 在调用时计算 |
| 无到期卡片 | 展示"今日已完成"空状态 | 页面空态 |
| 统计接口返回空/非数组 | 展示「暂无学习记录」，不白屏 | `loadState = 'empty'`（#005） |
| 统计页设备时钟与服务器日期不一致 | 优先按日期匹配今天；对不上时按后端固定下标 90 兜底 | `findNearestIndex`（#005） |
| 今日 `due` 为累计值顶高纵轴 | 历史柱偏矮；取全期统一上限，数字精度由详情卡承担 | 已知取舍（#005） |

## 6. 数据与依赖

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/fsrs/due-count` | GET | 参数 `endTs`，轻量计数 |
| `/api/fsrs/due` | GET | 参数 `endTs`，返回卡片数组 |
| `/api/fsrs/review` | POST | 提交评分与新状态 |
| `/api/fsrs/due-forecast` | GET | 学习统计：`data.days`（106 项，前 90 + 今天 + 后 15）；未来日 `cognitive`/`reviewAndNew`/`durationSeconds` 为 `null`，历史日 `due` 为 `null` |
| `/api/user/learning-config` | GET | 读取 FSRS 参数：`fsrsRequestRetention` / `fsrsMaximumInterval`（始终 number，非 `null`） |
| `/api/user/learning-config/fsrs-config` | PUT | 部分更新 FSRS 参数；只传改动字段；失败业务码 `2005` |

**版本约束**：`FSRS_VERSION = '5.4.1'`，必须与前端 ts-fsrs 版本一致，否则服务端可能拒绝或算出不同间隔。

## 7. 已知限制

- 页面在拉取 `due` 后不再刷新；若用户在其它设备复习过，本机列表会短暂过期。
- mock 分支仍保留在代码中，切换 `USE_MOCK` 会改变数据来源，属于 L3 改动。
- 预测接口的展示口径未与服务端对齐文档，调整前需确认。
- FSRS 参数默认值有两处载体（后端 DDL `0.900/36500`、前端 `utils/fsrs/params.js`），调整时必须同时改。
- 跨设备中途修改参数，本次运行内不刷新；需冷启动或重新进入复习页才生效。
- 参数请求失败且本机无缓存时用默认值计算，可能产生一次与用户偏好不一致的排期。
