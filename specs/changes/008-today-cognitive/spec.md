## 新增需求

### R1 完成判定与取数

- **AC-01** 当复习页进入「本地队列已清空」的完成态时，系统应调用一次今日认知接口（`GET /api/fsrs/due-forecast/today`）取当天数据，且不得为此再拉取 106 天的主接口。**只有以下三个时机算"进入完成态"**：① 首屏或下拉刷新后队列为空；② 评分提交成功后队列耗尽；③ 因单词不存在被静默跳过后队列耗尽。复习过程中（队列非空）、页面 `onShow` 的角标刷新、切 tab 均不得调用该接口。
- **AC-02** 当接口返回的 `due > 0` 时，系统应重新拉取当天队列：**有卡**则直接继续复习、不展示今日详情；**无卡**则按下条 `AC-13` 处理。
- **AC-03** 当接口返回的 `due === 0` 时，系统应展示今日复习详情卡（日期、四档分布、新学/复习/时长、完成文字）。
- **AC-04** 如果今日认知接口请求失败，系统应**仍按详情卡的版式展示，只是数值为空**：日期显示本地当天，四档数值与三列数值显示「—」、条形为空，不得展示旧的「✓ 今日复习已完成」页、不得白屏、不得额外弹错（错误提示只由请求层给出一次）。
- **AC-12** 当队列已清空但今日详情数据尚未返回时，系统应展示「加载中...」占位，**不得先渲染旧的「✓ 今日复习已完成」页**（该页在完成态永久下线）。
- **AC-13** 当接口返回 `due > 0` 且重新拉取队列后仍无卡片时，系统应展示今日详情卡，并记录一条缺陷日志（提示 `due` 与实际可出卡数不一致），用户侧不出现报错提示。
- **AC-05** 如果接口返回的 `date` 与本地当天不一致，系统应重新请求一次；日期标题按 `YYYY/MM/DD` 展示返回日期（如 `2026/10/28`），不得自行改写日期数值。

### R2 详情卡内容

- **AC-06** 详情卡应恒显示四行，自上而下为「简单」「认识」「模糊」「忘记」；某档为 `0` 时该行仍显示，条形为空、数值显示 `0`。
- **AC-07** 每行条形长度应按「该档数值 ÷ 四档之和」计算；四档之和为 `0` 时四条一律为空。
- **AC-08** 详情卡应展示三列统计：新学、复习、时长，数值取自 `reviewAndNew.newLearned`、`reviewAndNew.review`、`durationSeconds`；时长按 `时:分:秒` 展示，秒补零到两位；不足 1 小时省略小时段（`17:25`），0 为 `0:00`。
- **AC-09** 详情卡底部应只显示文字「今日复习完成」，不提供任何可点击元素（无返回首页、无刷新、无重试）。
- **AC-10** 当 `due === 0` 且四档之和为 `0` 时，系统应只显示「今日暂无复习记录」，不绘制四行明细与三列统计。
- **AC-11** 当 `due > 0` 且重新拉取队列后仍无卡片时，系统应只重拉**一次**并转而展示现有空闲态，不得反复请求该接口或队列接口；同一完成态内今日认知接口最多调用一次（下拉刷新或离开后重新进入除外）。

## 界面契约

| AC | 出现位置 | 形态 | 文案（逐字） | 用户动作 | 消失条件 |
|----|---------|------|-------------|---------|---------|
| AC-02 | 复习页完成判定后 | **不新增元素**；`due > 0` 且重拉后有卡时不展示详情卡、不加提示，直接出卡 | 不变 | 无 | 无卡可出时转 AC-13 |
| AC-12 | 复习页完成态，详情数据未就绪期间 | 居中一行「加载中...」（沿用页面既有 loading 样式），**不渲染**旧 `idle-card` 与「✓ 今日复习已完成」 | 「加载中...」 | 无 | 详情数据返回或失败 |
| AC-13 | 复习页完成态 | 与 AC-03 相同的详情卡（**不新增元素**）；仅控制台多一条 `warn` 日志 | 同 AC-03 | 无 | 同 AC-03 |
| AC-04 | 复习页完成态，详情接口失败 | **与 AC-03 相同的详情卡版式**，仅数值为空（条形无填充）；不新增提示条、不新增按钮 | 日期为本地当天；四档与三列数值逐字「—」；底部「今日复习完成」照常 | 下拉刷新可重取 | 刷新成功后有数值 |
| AC-03 | 复习页完成态，原 `.idle-card` 内容整体替换 | 一张卡片（沿用 `.card` 圆角/白底/阴影），自上而下 4 块：日期标题、四行分布、三列统计、完成文字 | 见 AC-06/08/09 | 无（只读） | 离开页面；或重新进入且 `due > 0` |
| AC-05 | 同 AC-03 的日期标题 | 标题居中，20px 加粗 `#303133` | `2026/10/28`（`YYYY/MM/DD`，取接口 `date`） | 无 | 与卡片一致 |
| AC-06 | 卡片第 2 块，四行纵向排列 | 每行三段：左侧表情图标（22px）、中间条形（轨道高 14px 圆角 7px，填充同色）、右侧数字（16px 加粗 `#303133`）在上 / 档位名（11px `#909399`）在下 | 图标与档位：😎「简单」、🙂「认识」、😐「模糊」、😕「忘记」；数字为对应值 | 无 | 与卡片一致 |
| AC-07 | 同上条形 | 填充宽度 = 该档 ÷ 四档之和 × 100%；填充色：简单 `#409EFF`、认识 `#5B8C7D`、模糊 `#E6A23C`、忘记 `#F56C6C` | — | 无 | 与卡片一致 |
| AC-08 | 卡片第 3 块，三列等宽横排 | 每列：数字（18px 加粗 `#303133`）在上 / 标签（11px `#909399`）在下；列间 1px `#E4E7ED` 竖线 | 「新学」「复习」「时长」；时长 `17:25`（超过 1 小时为 `1:11:45`，不足 1 分钟为 `0:25`，0 为 `0:00`） | 无 | 与卡片一致 |
| AC-09 | 卡片第 4 块，底部单行 | 居中纯文字，无背景块、无边框、无 `bindtap` | 「今日复习完成」 | 无（不可点） | 与卡片一致 |
| AC-10 | 同 AC-03 的卡片 | 卡片只保留日期标题 + 一行说明，不绘制四行三列 | 「今日暂无复习记录」 | 无 | 与卡片一致 |
