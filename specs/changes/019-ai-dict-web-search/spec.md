## 新增需求

### R1 开关的显示与读取

- **AC-01** 当设置页加载学习配置成功时，系统应读取 `aiDictWebSearch`，并按「`1` = 开启，`0` 或 `null` = 关闭」渲染开关状态。
- **AC-02** 当所选 AI 模型（忽略大小写与首尾空格）属于 `deepseek-flash`、`deepseek-v4-flash`、`deepseek-v4.1-flash` 三者之一时，系统应在管理员配置区「AI 推理强度」之后显示「联网搜索」开关。
- **AC-03** 当所选模型不属于上述集合，或尚未选择模型（当前值为空、界面显示「默认」）时，系统应**不显示**该开关（整项不渲染，不留空位）。
- **AC-04** 当用户切换模型时，系统应立即按新模型重新判定开关是否可见；开关因此隐藏时，系统**不得**修改或清空已保存的联网值。

### R2 保存

- **AC-05** 当用户切换「联网搜索」开关时，系统应把开关新值（开 = `1`，关 = `0`）与模型、温度、思维模式、推理强度**一起**提交，请求体固定包含 5 个字段。
- **AC-06** 当用户修改模型、温度、思维模式、推理强度中的任意一项并保存时，系统应在**同一请求**中提交当前的联网值（`0` 或 `1`），不得省略该字段；联网值从未设置时提交 `0`。
- **AC-07** 如果保存返回非 `200` 的业务码（如 `2005`），系统应保持界面原值（开关回到切换前状态），且不追加自定义提示——提示由请求层统一给出后端 `message`。
- **AC-08** 如果保存请求抛异常（网络失败 / 超时 / 401 后仍失败），系统应保持界面原值（开关复位），并在页面内记录错误；用户可见提示由请求层统一给出。
- **AC-09** 当保存成功时，系统应使用响应 `data` 中的模型、温度、思维模式、推理强度、联网值回填表单；响应缺少某个 AI 字段时保留本地值，不得把界面清空。

### R3 015 释义体例的兼容（回归，不改代码）

- **AC-10** 当 AI 查词结果返回短义项（`definitionCn` 较短，语源以「（源自…）」形式前置）时，系统应完整渲染释义、`usage`（长解释）与 `note`（固定搭配）三段，不得截断，也不得假设旧的长度上限。
- **AC-11** 当 AI 结果的 `wordType` 为「助动词」或其它中文标签时，系统应原样展示，不得因该值不在纠错页的「词性 code → 中文」映射表中而隐藏或改写。

### R4 查词请求（明确不变）

- **AC-12** 当用户发起 AI 查词时，系统应**不传** `webSearch` 字段，由服务端按用户配置与模型能力决定是否联网。

**界面契约附加说明**

1. **位置**：开关放在管理员配置区最末，位于「AI 推理强度」项之后；「AI 推理强度」只在思维模式开启时存在，因此思维模式关闭时开关直接跟随「AI 思维模式」。
2. **形态**：复用页面现有 `setting-item / setting-label / setting-title / setting-desc / setting-control` 与 `<switch>`，不引入新组件、不引入新样式文件。
3. **文案**：标题必须是「联网搜索」，描述必须是「先联网检索再作答（会显著增加查询时间）」；不得写成「开启联网」「网络搜索」等变体。
4. **动作**：只有右侧开关可点；点标题/描述不触发保存（与「AI 思维模式」一致）。
5. **消失条件**：模型非 flash 家族或为空 → 整项不渲染；保存失败 → 开关值复位，但开关本身不消失。

**不加东西（写死）**

| 场景 | 形态 |
|------|------|
| 模型为 `deepseek-v4-pro` 或为空 | **不加**置灰开关、**不加**「该模型不支持联网」提示；整项不渲染 |
| 保存失败（业务码 / 网络） | **不加**页面内错误条；只用请求层 toast |
| 保存中 | **不加** loading 图标；开关仍可点击，但页面忽略重复提交 |
| 普通用户（非管理员） | **不加**任何新入口；整个「管理员配置」区保持不可见 |

## 边界与异常

| 场景 | 预期行为 |
|------|----------|
| 未登录冷启动 | 配置读取沿用现有 `onLoad → loadConfig`；请求层等 token，失败不阻塞页面；开关按默认「关闭 + 隐藏」渲染 |
| 老版本后端没有 `aiDictWebSearch` 字段 | 按 `null` 处理 → 开关显示关闭；保存时提交 `0`，不报错 |
| `aiDictWebSearch` 为 `null` | UI 显示关闭；下一次任意 AI 配置保存后变为显式 `0` |
| 模型为「默认」（空） | 开关隐藏；保存其它配置时仍按已存值提交，不清空 |
| 切到 `deepseek-v4-pro` 后再切回 flash | 开关重新出现，且保持切换前的选择 |
| 连续快速切换开关 | 保存期间忽略后续保存请求，最终值以最后一次成功响应为准；不得出现界面与库不一致 |
| 后端返回 `2005` | 界面保持原值，toast 后端 `message`；库不变 |
| token 失效（401） | 由请求层重登重试；仍失败则保持原值并提示 |
| 服务端因模型不支持而降级为不联网 | 前端不感知、不提示（服务端行为，见对接文档 §7） |

## 数据契约

**读取** `GET /api/user/learning-config`（只列本次用到的字段）

| 字段 | 类型 | 前端用法 |
|------|------|----------|
| `aiDictModel` | string \| null | `null` / 空 → 视为「默认」；决定开关是否可见 |
| `aiDictTemperature` | number \| null | 回填输入框（字符串化），现有行为 |
| `aiDictThinking` | 0 \| 1 \| null | `=== 1` → 开启，现有行为 |
| `aiDictReasoningEffort` | string \| null | 回填 picker，现有行为 |
| `aiDictWebSearch` | 0 \| 1 \| null | `=== 1` → 开关开启，其余一律关闭 |

**保存** `PUT /api/user/learning-config/ai-dict-config`（全量覆盖，必须 5 字段齐全）

| 字段 | 类型 | 提交规则 |
|------|------|----------|
| `aiDictModel` | string \| null | 空串 → `null` |
| `aiDictTemperature` | number \| null | 空串 → `null`，否则 `parseFloat` |
| `aiDictThinking` | 0 \| 1 | 布尔转 `0/1` |
| `aiDictReasoningEffort` | string \| null | 空 → `null` |
| `aiDictWebSearch` | 0 \| 1 | 布尔转 `0/1`；**任何时候都必须出现** |

**错误码**：`2004`（参数校验）、`2005`（业务校验，`aiDictWebSearch` 非 0/1）、`4001`（未登录）——均由请求层统一提示。

**支持联网的模型集合**（展示用镜像，忽略大小写与首尾空格）：`deepseek-flash`、`deepseek-v4-flash`、`deepseek-v4.1-flash`。
与后端 `AiDictModelSupport.WEB_SEARCH_MODELS` 保持一致；后端新增模型时前端同步。
