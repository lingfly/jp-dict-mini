## 执行约定

1. **T01–T09 是请求层与登录改动，必须连续做完再动页面**，否则中间态行为不一致。
2. **界面形态严格按 `spec.md` 的「界面契约」表**：位置、形态、文案、动作逐行照做，不要自行增加提示条或按钮。
3. 勾选表示**代码已写完**；验证结果填在「验收记录」。无法自行验证的项要明确标注给用户。
4. 提交格式：`fix(request): 401 并发治理 [#001]`。
5. 发现范围外问题记 `TODO.md`，不在本次顺手改。
