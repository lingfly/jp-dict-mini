## 执行约定

1. **一次只做一个任务。** 做完 → 验证 → 勾选 → 提交，再开始下一个。
2. **提交信息带编号**：`feat(home): 增加开关 [#001]`。
3. **发现新问题不顺手改**：记到 `TODO.md`，必要时新建 change。
4. **每个任务结束时自问**：这条改动，三个月后的我能看懂为什么吗？
